# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

On release, immediately spring the fixed vertical boost back to the tab height alongside travel deceleration; never hold it until the opacity fade. Pointer speed must visibly drive strong expansion and horizontal stretch. On fast travel and braking, preserve volume-like squash/stretch: horizontal elongation pairs with vertical compression, target overshoot then produces horizontal recoil and vertical bounce. At high-speed arrival, the leading edge must feel as if it hits the destination: keep most velocity stretch trailing behind it, soften forward center overshoot, and retain only a short rebound instead of letting the full symmetric lens spill far beyond the first or last tab. After the first contact, rebound velocity must not re-excite fresh deformation; allow one clean recoil, then damp width, height, and optical-center bias smoothly to rest without sticky micro-oscillations. Travel and collapse must overlap and preserve one continuous travel velocity; never jump, restart the travel spring, or wait until arrival before shrinking. Keep glass visibility separate from shape deformation and begin the final optical attenuation once shape collapse has settled and positional motion has entered its low-amplitude tail, before the travel spring is fully at rest.
